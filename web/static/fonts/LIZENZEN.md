# Schriftlizenzen

Alle drei Familien liegen als Datei im Projekt und werden per `@font-face`
aus `assets/lifelog.css` geladen. Nichts wird von einem fremden Server nachgeladen.

| Familie | Rolle | Lizenz | Öffentliche App |
|---|---|---|---|
| **Manrope** 400/500/600/700 | Display — Titel, Kennzahlen, Abschnittslabels | SIL OFL 1.1 | unproblematisch |
| **Source Sans 3** 400/600 | Text und Oberfläche, inkl. Datum und KW | SIL OFL 1.1 | unproblematisch |
| **iA Writer Mono S** 400 | nur Capture-Zeile und Code | SIL OFL 1.1 | unproblematisch |

Die OFL verlangt: Lizenztext mitliefern, die Schriften nicht separat verkaufen,
reservierte Namen bei Änderungen nicht weiterverwenden. Solange die Dateien
unverändert bleiben, ist das erfüllt.

Frühere Stände nutzten URW Gothic (AGPL) und iA Writer Quattro. Beide sind
nicht mehr eingebunden und wurden aus dem Projekt entfernt.
